Ex No : 05 — Java Applet Programs

Aim

  • To understand the concept of Java applets.
  • To write simple Java applet programs for displaying text and graphics.
  • To learn basic applet lifecycle methods.
  • To run and test applets using an applet viewer or browser.

Algorithm

  • A Java applet is a small application that runs in a web browser or applet viewer.
  • Extends java.applet.Applet or javax.swing.JApplet.
  • Uses methods like init(), start(), paint(), and stop().
Aim + Algorithm + Code (one text file)

Aim, Algorithm, rendu program code ellam oru .txt file-la download aagum.

Program 1 : E_HelloApplet.java

import java.applet.Applet;
import java.awt.Graphics;

public class E_HelloApplet extends Applet {
    public void paint(Graphics g) {
        g.drawString("Hello, Java Applet..!", 50, 50);
    }
}

Program 2 : E_HelloApplet.html

<html>
  <body>
    <h1>test</h1>
    <applet code="E_HelloApplet.class" width="300" height="200"></applet>
  </body>
</html>

Run Commands

java -version
javac E_HelloApplet.java
appletviewer E_HelloApplet.html

Rendu file-um same folder-la irukkanum. JDK 8 venum.

Expected Output

"Applet Viewer" window-la Hello, Java Applet..! nu theriyum.

Result

Java applet program successfully created, compiled and executed using appletviewer.
