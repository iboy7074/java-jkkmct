Java Packages & Importing

Aim

  • To understand the concept and use of packages in Java.
  • To learn how to use built-in and user-defined packages.
  • To learn how to import classes from other packages.

Algorithm / Concept

  • A package is a namespace used to organize classes and interfaces.
  • Two types of packages are built-in packages and user-defined packages.
  • Examples of built-in packages are java.util and java.io.
  • The import keyword is used to access classes from another package.

Benefits of Packages

  • Organizes code.
  • Avoids name conflicts.
  • Provides better access control.

Program

Click the button to copy the Java program.

import java.util.Scanner;

public class C_BuiltInPackageDemo {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.nextLine();

        System.out.println("Hello, " + name + "!");

        sc.close();
    }
}

Sample Output

Enter your name: Arun
Hello, Arun!

Result

Thus, the Java program using the built-in java.util package and Scanner class was executed successfully.
